# Product Listing App Flutter

Developed as part of Week 9 of the Bihe Nepal Flutter Internship tasks.

## Features
- **Product Model**: Data parsing from FakeStoreAPI
- **Responsive GridView**: Display with thumbnail image, dynamic title, USD price and ratings
- **Real-time Search Filter**: Instant substring title query matching
- **State Handling**: Loading indicator, network error retry and empty search state
- **Pull to Refresh**: Seamless list refresh on scroll
